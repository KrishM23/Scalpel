Developers

Two calls to your first debiased model.

Authenticate with an API key, queue an edit job, poll for the report. Full OpenAPI at /docs.

Get an API key OpenAPI docs
1 · Queue a surgery
curl
curl -X POST https://api.scalpel.ai/v1/edit-jobs \
  -H "X-API-Key: $SCALPEL_KEY" -H "Content-Type: application/json" \
  -d '{
    "model_id": "openai/clip-vit-base-patch32",
    "bias": "gender_profession",
    "mode": "edit",
    "options": { "num_directions": 4, "calibrate": true },
    "webhook_url": "https://yourapp.com/hooks/scalpel"
  }'
# → 202 { "id": "job_…", "status": "queued", … }
2 · Fetch the report
curl
curl https://api.scalpel.ai/v1/edit-jobs/$JOB_ID/report \
  -H "X-API-Key: $SCALPEL_KEY"

# HTML compliance artifact:
# GET /v1/edit-jobs/$JOB_ID/report.html
