Privacy

How Scalpel handles account and workspace data. Last updated August 5, 2026.

What we collect

When you create a workspace we store your name, email, company name, password hash, tenant identifier, and issued API key. Job metadata (model ids, bias specs, statuses, reports) is stored for your tenant so the console and API can function.

How we use it

Account data authenticates you and maps API keys to tenants. Job data runs surgeries, produces audit reports, and enforces plan limits. We do not sell personal information.

Models and content

Model identifiers you submit are used to load and edit models for your jobs. Optional weight artifacts remain associated with your tenant. You are responsible for having rights to the models and data you process.

Retention

Account and job records persist while your workspace is active. You may request deletion of your account by contacting sales@scalpel.ai. Self-hosted deployments retain data according to your own infrastructure policies.

Security

Passwords are stored with salted PBKDF2 hashes. API access requires a secret key. See Security for product controls.

Contact

Privacy questions: sales@scalpel.ai.
