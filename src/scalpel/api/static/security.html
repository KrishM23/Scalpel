Security

Built for teams that cannot hand-wave model risk.

Tenant isolation, key-authenticated APIs, and compliance artifacts on every job — designed for production bias operations.

  • 01
    API authentication Every /v1 request requires X-API-Key or Bearer auth. Keys map to tenants; comparison is constant-time.
  • 02
    Tenant isolation Jobs, reports, alerts, and usage are scoped to the authenticated tenant. Workspaces cannot list or mutate each other’s data.
  • 03
    Audit artifacts Succeeded jobs produce structured JSON reports and printable HTML — circuit localization, edits applied, WEAT before/after, retention.
  • 04
    Artifact handling Edited weights are optional (save_artifact). When enabled, downloads are keyed to the owning tenant only.
  • 05
    Transport & headers Security headers on responses, request IDs for support, configurable CORS, optional webhook HMAC signing.
  • 06
    Operations /health and /ready for load balancers. Stale job reaping and recovery after process restart.
